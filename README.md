This repo sets up a fresh Mac with Claude Code on the Vercel AI Gateway, pstack, LazyVim, Ghostty, and the Paneru scrolling window manager. Paste `curl -fsSL https://raw.githubusercontent.com/lvvittor/macos/main/bootstrap.sh | bash` into Terminal.app. Add `-s -- --minimal` after `bash` to install only Claude Code, which needs no admin password. When you're done, `bash ~/mac-setup/teardown.sh` removes the key, the configs, and Claude Code, and puts back any files it replaced.
